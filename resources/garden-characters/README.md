# Toddl garden characters — approved set (12)

Trimmed RGBA PNGs, cream-matted, transparent background, 16 px pad. Style: flat 2D pastel kawaii, dot faces, no outline.

watering-can, strawberry, pea, lettuce, carrot, tomato, blueberry, pumpkin, apple, broccoli, cabbage (red), orange.

- `png/` — the sprites (330–840 px on the long side)
- `manifest.json` — per sprite: size, seed, workflow and post-processing steps (regenerable with tools/comfy in the Toddl repo)
- `contact-sheet.png` — all twelve on the game gradient and on a checkerboard
- In-game display sizes: base height 0.30 × stage height, times the per-crop scale in `crop-scale.json`

Not included: radish (parked), corn, watermelon, cucumber, grapes, beet, turnip, leek, kale (not yet made).
